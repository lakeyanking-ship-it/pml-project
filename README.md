# Practical Machine Learning Prediction Project

Author: LaKeya King

## Project Overview
The goal of this project is to predict the manner in which participants performed barbell lifts using accelerometer data collected from wearable devices.

The outcome variable is **classe**, which identifies whether the exercise was performed correctly or incorrectly.

## Files Included
- `Prediction_Project.Rmd` — full reproducible R Markdown analysis
- `Prediction_Project.html` — compiled HTML report for grading
- `README.md` — project summary

## Model Used
Several models were evaluated, including:
- Decision Tree
- Random Forest

The **Random Forest** model was selected as the final model because it produced the highest validation accuracy (~99%) and lowest expected out-of-sample error (~1%).
